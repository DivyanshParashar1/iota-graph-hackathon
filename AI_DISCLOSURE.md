# AI assistant disclosure

The hackathon allows AI assistants if their use is disclosed and the team can explain the model, queries,
architecture and decisions. This file states what was AI-generated and what the human owns.

## What the AI did

* **Tool**: Claude Code (Anthropic), running autonomously in one cloud session.
* **Input**: a human-written product spec (`idea.md`) and build plan (`plan.md`), plus verified FalkorDB syntax notes
  (`reference/FALKORDB_VERIFIED.md`) and an offline environment prepared by the human.
* **Output**: most of the code in this repository: the `ripple/` package (ingest, tools, agents, MCP server, API),
  every Cypher file in `graph/queries/`, the synthetic data generator and its committed output in
  `data/synthetic/`, the scenario files, the pandas ground truth, the evals, the tests, the React UI, the Docker and
  Render files, the generated README sections, `docs/numbers.md` (measured by `scripts/report_numbers.py`) and the
  first draft of `docs/blog.md`.
* **Synthetic text**: contracts, SOPs, postmortems and chat threads are template-generated by
  `ripple/ingest/synth_docs.py` (code written by the AI), not free-form LLM text. All companies and people are
  fictional and tagged `[SYNTH]`.
* **At runtime**: agents run in deterministic scripted mode by default. With `ANTHROPIC_API_KEY` set, Claude
  (`claude-opus-5-5`) can drive the same tools through a tool-use loop whose answers are checked by an ID validator.
